خطوات تجهيز الحسابات
  1. في Google Cloud فعّل Gmail API، وجهّز OAuth consent screen وأضف حسابك كمستخدم اختبار.
  2. أنشئ OAuth Client من نوع Web application وأضف Redirect URI الظاهر هنا.
  3. احفظ البيانات، واضغط ربط Gmail واختر حساب الاستقبال. وضع Google Testing قد يتطلب إعادة الربط دوريًا.
  4. من Meta جهّز تطبيق Pages والتصاريح المطلوبة: pages_show_list وpages_read_engagement وpages_manage_posts، ثم خذ توكن الصفحة نفسها.
  5. تأكد من صلاحية التوكن ونسخة API وشروط App Review في حساب Meta.
